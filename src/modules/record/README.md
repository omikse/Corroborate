# Result record

Collects the findings and facts from up to six and three nodes, and up to three locations. It
stores the result JSON and the evidence trail in `results\` next to the program, and gives the
location the findings agree on. Output: `location`.

Files: `mod.rs` (name, label, ports), `node.rs` (the node in the workbench: the location its inputs agree on, its window and its part of the result file).
