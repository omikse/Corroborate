# Manual data (source)

Facts typed in by a person: date, time, place, coordinates, notes, and any extra fields.
Coordinates typed here become a location. Ports: outputs `place` (location), `time`, and `facts`
(JSON). No inputs.

Files: `mod.rs` (name, label, ports), `node.rs` (the node in the workbench: its window, the area its coordinates give, the rows passed to plugins, its part of the result file).
