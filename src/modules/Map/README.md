# Map (view)

Draws a location on a world map in the Robinson projection, over the NASA Blue Marble image. Green
means the area adds to the result, red means it subtracts. Input: `location`. No outputs.

Files: `mod.rs` (name, label, ports), `node.rs` (the node in the workbench: the map on the canvas and in its window), `earth.idx` (NASA Blue Marble, public domain), `coastlines.txt` (Natural Earth 1:110m).
